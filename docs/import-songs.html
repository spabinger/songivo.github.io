Files and search

Importing Songs

Songivo imports ChordPro, plain text, PDF lead sheets, image files, SongBook Pro packages, and online search results into the selected library.

Import from files

  1. Open the import flow from the library or quick actions.
  2. Select one or more ChordPro, text, PDF, image, or SBP files.
  3. Review any preview or duplicate prompt shown by Songivo.
  4. Save the songs into the selected library.
  5. Add tags, key, BPM, duration, and other metadata after import.

Import from online search

Use Ultimate Guitar or E-Chords search when you want to find a chart from inside Songivo. Preview the result before saving it, and keep provider selections tuned to the sources you actually use.

Duplicate handling

  • Keep both when you need a second arrangement.
  • Merge metadata when the imported chart should enrich an existing song.
  • Cancel when the match is not the song you intended to import.

Free song additions

Creating or importing a song uses one free song addition until unlimited song additions are unlocked. Deleting a song later does not restore a free addition, so preview imports before saving.
