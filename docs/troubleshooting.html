Troubleshooting

Start with the least invasive check. Most problems are caused by library context, missing permissions, unavailable iCloud, or an incomplete import.

Import does not look right

  • Confirm the file type is supported: ChordPro, text, or PDF.
  • For PDFs, revisit the preview step and check rotation, crop, perspective, and contrast.
  • For text charts, inspect whether the source needs ChordPro cleanup after import.
  • Check duplicate prompts before assuming the import failed.

Sync is behind

  1. Confirm the device is online.
  2. Confirm iCloud is available for the Apple ID on the device.
  3. Use Sync Now.
  4. Open sync status and logs if the device still looks behind.
  5. Contact support with diagnostics if the same issue repeats.

Band changes do not appear

  • Check that the correct band library is selected.
  • Confirm the member has accepted the band invite.
  • Run band sync and review band sync health.
  • Resolve any Conflict needs review items.

Tuner cannot hear input

Confirm microphone permission in iOS Settings and make sure another app is not holding the microphone. The tuner uses microphone input for pitch detection and does not store audio.

When contacting support

Include your device model, iOS version, Songivo version, what you expected, what happened, and screenshots or diagnostics if available.
