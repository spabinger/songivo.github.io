Teams

Band Libraries

Band libraries keep songs and setlists separate from other libraries (e.g., My Library), so collaboration does not overwrite material of other bands.

Use My Library for personal material and a band library for charts that should be shared with a band. Copy songs explicitly when songs should move between contexts.

Create or join a band

  1. Open Settings and choose Band.
  2. Create a band when you are the leader, or join from an invite when another member created it.
  3. Select the band library before importing or copying shared songs.
  4. Use sync status and logs when shared changes do not appear yet.
  5. Confirm the active library before rehearsing so you do not edit a personal copy by mistake.

Shared library rules

  • Band songs and setlists live in the selected band library.
  • My Library and each band library remain independent.
  • Songs move between libraries only through explicit copy actions.
  • Leader-only deletion protects the shared band library from accidental removal.
  • Band-song annotations stay private per user.

Active band limits

The free tier includes 5 active bands. Leaving or deleting a band frees an active band slot, and each €0.99 extra active-band purchase adds one more slot.

Conflicts

Offline or concurrent shared edits can be marked as Conflict needs review. Open the review flow and choose which local fields to keep versus the synced band version.
