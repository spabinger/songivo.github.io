Personal sync

iCloud Sync

Songivo uses your Apple iCloud account to sync personal songs, setlists, tags, links, and theme settings between your devices.

What sync covers

  • Personal songs, PDFs, ChordPro text, tags, song links, and setlists.
  • Theme settings and selected appearance preferences.
  • Foreground and network recovery sync attempts, plus manual Sync Now.

Manual sync

  1. Open Settings.
  2. Check that iCloud is available.
  3. Use Sync Now for an explicit sync attempt.
  4. Open sync status or logs if the result is unclear.

Recovery tools

Use repair and reset tools only when the app directs you there or support asks for them. Hard reset and re-sync is destructive to the local copy before rebuilding from cloud data.
