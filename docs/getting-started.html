Getting Started

Songivo is built around one idea: keep your music organized before the show and readable when you are playing.

First steps

  1. Open Songivo and complete any first-run profile setup shown by the app.
  2. Choose My Library for personal songs, or select a band library when working with shared material.
  3. Import a ChordPro, text, or PDF song.
  4. Open the song, check the title, artist, key, BPM, and display settings.
  5. Create a setlist when you are preparing songs for rehearsal or a show.

Main areas

LibrarySearch, filter, tag, favorite, duplicate, delete, and open songs.
ViewerRead ChordPro or PDF songs with performance controls nearby.
SetlistsArrange a night of music with slot notes and transpose overrides.
SettingsAdjust appearance, sync, diagnostics, band libraries, and recovery tools.

Good setup habits

  • Add useful metadata early, especially artist, key, BPM, duration, song number, and tags.
  • Use setlists for performance order instead of renaming songs for each show.
  • Keep personal songs in My Library and shared band material in the matching band library.
  • Check iCloud availability before relying on sync between devices.
