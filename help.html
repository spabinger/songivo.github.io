Import

Import songs

Add ChordPro, text, or PDF files through the file picker, or search supported online sources from inside Songivo.

  • Choose the target library before importing.
  • Review duplicate prompts before keeping, merging, or cancelling.
  • Use tags and metadata after import to keep sets searchable.
ChordPro

Edit ChordPro songs

Use the editor to maintain lyrics, chords, sections, metadata, and display preferences.

  • Transpose at song level without changing the original chart text.
  • Use the ChordPro assist toolbar for section and directive helpers.
  • Choose Standard, Nashville, or Roman notation for display.
PDF

Process PDFs

PDF imports open in a preview step so you can adjust the document before saving it as a song.

  • Rotate pages that were scanned sideways.
  • Crop or correct perspective when a page was photographed.
  • Use contrast, grayscale, and optimization presets for cleaner stage reading.
Setlists

Create a setlist

Build a set for My Library or a selected band library, then reorder slots for the night.

  • Add a performance date when helpful.
  • Use slot notes for cues, intros, transitions, or reminders.
  • Override transpose per slot when a song needs a different key in one set.
Live

Use live mode

Open full-screen performance mode when you are ready to play.

  • Start, pause, or reset auto-scroll from the live controls.
  • Use swipe or keyboard navigation for setlist movement.
  • Open tap tempo or tuner without leaving the chart.
Annotations

Draw on music

Use annotation mode to mark ChordPro and PDF songs with Apple Pencil or touch.

  • Performance gestures are gated while annotation mode is active.
  • Annotations scale with content size changes.
  • Band-song annotations stay private per user.
iCloud

Sync My Library

Personal songs, sets, tags, links, and settings sync through your iCloud account.

  • Use Sync Now for an explicit sync attempt.
  • Check sync status and logs when a device appears behind.
  • Use advanced repair options only when the app directs you there.
Band

Share a band library

Create or join a band to keep a separate shared song and setlist library.

  • Leaders create bands and invite members.
  • Members can leave; leaders control band deletion.
  • Offline shared edits can enter Conflict needs review.
Gig mode

Push the current song

Accepted band members can push the active song so listening devices switch to the same chart.

  • Select the shared band before using gig song push/listen.
  • Keep gig mode enabled on devices that should follow.
  • If a song is missing locally, the receiving device reports it instead of switching blindly.
Export

Export and share

Share songs or sets through native iOS share targets.

  • Export the current song as PDF.
  • Bulk export selected songs into one combined PDF.
  • Export set summaries or full set PDF packages.
Tuner

Use the tuner

Open the tuner overlay from quick actions when the microphone is available.

  • Grant microphone permission when iOS asks.
  • Watch the frequency and accuracy feedback while tuning.
  • Close the overlay to return to the same song view.
Troubleshooting

When something looks stuck

Start with the least invasive checks before using advanced recovery.

  • Confirm iCloud is available and the device is online.
  • Use sync logs or diagnostics when contacting support.
  • Avoid destructive reset flows unless you understand the warning shown in the app.
