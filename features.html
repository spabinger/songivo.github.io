Feature overview

Everything a musician needs.

Songivo combines a song renderer (ChordPro, PDF), library management, setlist planner, live performance controls, annotations, and shared band libraries in one iPhone and iPad app.

Library

Song management

Import, create, edit, duplicate, favorite, tag, search, and copy songs between My Library and band libraries.

Songs

Chord charts

Parse ChordPro as well as txt files, transpose songs, choose notation modes, and tune layout per song.

PDF

PDF sheets

Preview PDFs before import, rotate, crop, correct perspective, boost contrast, optimize, view, and annotate them during rehearsal or performance.

Sets

Setlists

Create sets, reorder slots, add notes, group linked songs, and mark played and skipped songs.

Live

Performance mode

Use full-screen playback, swipe or keyboard navigation, auto-scroll, tap tempo, tuner overlay, and a floating live bar.

Pencil

Annotations

Draw on ChordPro and PDF content with scaled persistence. Band-song annotations stay private to each member.

Multiple devices

Personal sync

Sync songs, sets, tags, links, and settings between devices with automatic sync functionality.

Band

Band sharing

Create and join bands, sync independent band libraries, review conflicts, manage member invites, and push the current gig song to bandmates.

Import

Import and export

Import ChordPro, text, PDF, image, Ultimate Guitar, and E-Chords results. Export songs, bulk PDFs, set summaries, and combined set PDFs.

Tuner

Built-in tuner

Use microphone pitch detection and visual tuning feedback without leaving the performance surface.

Purchases

Clear upgrade limits

Start with 5 song additions and 5 active bands, then unlock unlimited song additions or add extra active band slots when needed.
