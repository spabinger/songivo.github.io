Feature overview

Everything a working set needs.

Songivo combines a song library, ChordPro renderer, PDF workflow, setlist planner, live performance controls, annotations, iCloud sync, and shared band libraries in one iPhone and iPad app.

Library

Song management

Import, create, edit, duplicate, favorite, tag, search, and copy songs between My Library and band libraries.

ChordPro

Chord charts

Parse ChordPro, detect plain-text chord lines, transpose non-destructively, choose notation modes, and tune layout per song.

PDF

PDF sheets

Preview PDFs before import, rotate, crop, boost contrast, optimize, view, and annotate them during rehearsal or performance.

Sets

Setlists

Create dated sets, reorder slots, add notes, override transpose per slot, group linked songs, and export summaries or full set PDFs.

Live

Performance mode

Use full-screen playback, swipe or keyboard navigation, auto-scroll, tap tempo, tuner overlay, and a floating live bar.

Pencil

Annotations

Draw on ChordPro and PDF content with scaled persistence. Band-song annotations stay private to each player.

iCloud

Personal sync

Sync songs, sets, tags, links, and settings through iCloud with manual sync, automatic foreground sync, logs, and diagnostics.

Band

Band sharing

Create and join shared bands, sync independent band libraries, resolve edit conflicts, and push the current gig song to bandmates.

Import

Import and export

Import ChordPro, text, PDF, and supported online search results. Export songs, bulk PDFs, set summaries, and combined set PDFs.

Tuner

Built-in tuner

Use microphone pitch detection and visual tuning feedback without leaving the performance surface.
