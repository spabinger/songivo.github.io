# Screenshot Slots

Use this folder for public website screenshots before copying to the GitHub
Pages repository.

Recommended names:

- `ipad-live-mode.png`
- `iphone-library.png`
- `ipad-setlist.png`
- `ipad-band-library.png`
- `ipad-pdf-annotation.png`

The first site version uses CSS-rendered placeholders, so missing screenshots do
not break the layout.
